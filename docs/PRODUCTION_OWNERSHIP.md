# Production ownership

Production FinFolk is built and deployed from https://github.com/hoebat/finfolk-next using the Clojure-authored xt.substrate backbone. This repository retains legacy implementation and survey acquisition/archive jobs, but must not deploy GitHub Pages or claim finfolk.com.au. The Pages deployment job and CNAME are retired. Existing legacy data is retained; new application accounts use the current Next auth/database service.
